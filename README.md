# SMART TIME — Android (Kotlin)

Native Android implementation of SMART TIME. The original React/Vite project remains separate and unchanged.

## Phase 1 — Foundation
- Kotlin + Jetpack Compose application shell
- Arabic RTL layout and bottom navigation foundation
- Approved navy / black / gold visual palette
- Central backend base URL configuration
- Android internet permission; no API secrets embedded in the app

## Requirements
- Android Studio with JDK 17
- Android SDK 35
- Gradle 8.9 or compatible wrapper generated by Android Studio

## Backend
The current API base URL is configured in `app/build.gradle.kts` as a build-time constant:
`https://smart-time-production-661f.up.railway.app/`

This is only the connection configuration. Authentication, expenses, chat, and database compatibility will be implemented and verified in their own phases. No backend schema or production data is modified by this Android client.

## Build
Open this repository in Android Studio and allow Gradle sync. Then run the `app` configuration on an emulator or Android device.
